# CashFlow Ecosystem

Полная сборка сайта CashFlow Ecosystem для публикации через GitHub Pages.

## Состав проекта

- `index.html` — главная страница экосистемы.
- `fast-flow-super-fast-flow.html` — Fast Flow / Super Fast Flow.
- `growing-flow.html` — Growing Flow.
- `vip-fast-flow.html` — VIP Fast Flow.
- `year-flow.html` — Year Flow.
- `cumulative-flow.html` — Cumulative Flow.
- `withdrawal-calculator.html` — Калькулятор вывода.
- `manifest.webmanifest`, `sw.js`, `assets/icon-192.png и assets/icon-512.png` — файлы PWA и значок приложения.

## Публикация на GitHub Pages

1. Распакуйте архив.
2. Загрузите **всё содержимое** папки в корень GitHub-репозитория, сохранив структуру `assets/`.
3. В настройках репозитория откройте **Settings → Pages**.
4. Выберите публикацию из нужной ветки (обычно `main`) и папки `/ (root)`.
5. Главная страница будет доступна по адресу GitHub Pages вашего репозитория.

## Что оптимизировано

- Добавлен общий адаптивный технический слой для мобильных устройств, планшетов и компьютеров.
- Улучшены базовые ограничения ширины, прокрутка таблиц, поведение полей и доступность фокуса.
- Уважена системная настройка уменьшения анимации.
- Добавлены отсутствовавшие в исходной загрузке PWA-файлы `manifest.webmanifest`, `sw.js` и `assets/icon-192.png и assets/icon-512.png`, на которые ссылались страницы.

## Сохранность расчётов

В этой технической сборке не менялись тарифные значения, формулы, расчётные алгоритмы, структура карточек калькуляторов и назначение кнопок. Исходные HTML-файлы сохранены; к ним добавлен только общий CSS-слой адаптации. Перед финансовым использованием сверяйте исходные тарифы с актуальными условиями проекта.
